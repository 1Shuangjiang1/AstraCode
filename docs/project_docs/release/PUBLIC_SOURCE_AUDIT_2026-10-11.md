## 实施

- `packaging/export_public.py` 使用允许列表复制到新目录，拒绝覆盖已有目标，检查凭据模式、JSON 与相对文件链接，生成源码 SHA-256 清单和 ZIP。
- `packaging/publish_github.ps1` 使用本机 Git Credential Manager 的现有登录，校验账号和清单哈希后发布到空公开仓库。遇到已有历史拒绝覆盖；凭据只在进程内使用。
- 真实测试取消固定本机盘符，改用系统临时目录，可由 `S_FULL_TEST_BASE` 覆盖。
- 新增 5 项导出回归与 GitHub 离线 CI。真实模型套件保持手动执行，不作为 CI 费用项。
- 修正文档中的过期审批/Plan 状态和数据配置描述。

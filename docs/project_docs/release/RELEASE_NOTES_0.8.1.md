# AstraCode Workbench 0.8.1

这是一次界面体验修订版，Agent 核心协议和已有对话数据保持兼容。

## 本次更新

- 新手指南扩展为五步可视化导览，使用缩小版工作台、高亮框、箭头和说明卡指出实际按钮位置；
- 删除旧指南中没有明确含义的装饰方块；
- 用户界面统一使用“文件”，不再使用“产物”；
- 本轮文件卡片的三个操作改成紧凑的一体式按钮组；
- 修复浅色主题 Markdown 代码块，采用浅灰蓝背景、深色代码和清晰边框；
- 保留 Markdown 渲染、红绿 Diff、打开文件夹和一键撤销。

## 安装

运行 `AstraCode-Workbench-v0.8.1-Windows-x64-Setup.exe`。升级安装不会主动删除 `%LOCALAPPDATA%\s_full` 中的既有会话和日志，也不会携带开发者 API Key。

## 已知边界

- 当前仅构建 Windows x64；
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示；
- 文件事务主要覆盖文本文件，二进制和外部服务副作用不能一键撤销。
